# Sistema de Gestión de Biblioteca (C#)

Proyecto simulado para la asignatura Programación Avanzada en C#.
Aplica POO (abstracción, herencia, polimorfismo y encapsulación),
interfaces, inyección de dependencias y excepciones personalizadas.

## Ejecutar
```bash
dotnet run --project Biblioteca/Biblioteca
```

## Flujo de trabajo
- Ramas `feature/*`, `docs/*` y `ci/*` creadas desde `master`.
- Cambios integrados solo mediante Pull Request.
- Pipeline de CI en GitHub Actions que compila el proyecto en cada PR.
